# Contexto Técnico

## Stack Tecnológica
- **Frontend**: React com TypeScript
- **Estilização**: Tailwind CSS
- **Build Tool**: Vite
- **Linting**: ESLint
- **Formatação**: Prettier
- **Testes**: (A definir)
- **Persistência de Dados**: localStorage
- **Hospedagem**: (A definir)

## Configurações
- Node.js (versão recomendada: >= 16.x)
- npm ou yarn como gerenciador de pacotes
- TypeScript configurado com regras estritas
- Vite para desenvolvimento rápido e eficiente

## Restrições Técnicas
- Compatibilidade com navegadores modernos (últimas duas versões dos principais navegadores)
- Armazenamento limitado ao localStorage (sem backend no momento)
- Preocupações com a performance em dispositivos móveis
- Acessibilidade (WCAG 2.1 AA)

## Dependências Principais
- React: biblioteca central para UI
- TypeScript: superset de JavaScript para tipagem estática
- Tailwind CSS: framework de CSS utilitário para estilos
- Vite: ferramenta de build moderna e rápida
- PostCSS: processador de CSS para plugins como Tailwind
- ESLint: linter para manter qualidade de código
